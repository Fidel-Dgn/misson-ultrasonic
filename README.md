# misson ultrasonic
La mission Ultrason consiste à mesurer en temps réel la distance d’un obstacle à l’aide d’un capteur HC‑SR04, en exploitant les interruptions matérielles du STM32G431KB. Le système détecte les fronts montants et descendants du signal ECHO, calcule la durée de l’impulsion ultrasonique, puis en déduit la distance. Une LED indique visuellement l’état de la mesure.
